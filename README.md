# VideoCallBlocker (영상통화 지킴이)

자녀의 안드로이드 스마트폰(갤럭시 등)에서 통신사 기본 영상통화 시간을 모니터링하고, 월 한도를 초과할 경우 자동으로 통화를 종료하여 요금 폭탄을 방지하는 자녀 보호 안드로이드 애플리케이션입니다.

---

## 🎯 주요 기능

1. **발신 영상통화 자동 감지 및 실시간 사용량 측정**
   - 전화 통화(`CALL_STATE_OFFHOOK`) + 카메라 작동 여부 + 통화 UI 포그라운드 여부를 조합하여 일반 음성통화가 아닌 **통신사 영상통화**를 정확하게 판별합니다.
   - 통신사 무료 제공량(예: 월 300분)은 **발신 통화만 차감**되므로, 상대방이 걸어온 수신 영상통화는 차단하거나 차감하지 않습니다.
   - 카카오톡 페이스톡 등 데이터 기반 영상통화는 무제한 데이터 요금제를 사용하므로 건드리지 않습니다.

2. **월 한도 초과 시 실시간 자동 종료**
   - 설정한 월 한도(기본 250분 권장)에 도달하면 `TelecomManager.endCall()`을 통해 즉시 통화를 종료합니다.
   - **통화 중 250분이 넘어가는 경우**: 실시간으로 초 단위 계산을 진행하여 250분에 도달하는 즉시 통화가 자동 종료됩니다.

3. **매월 자동 리셋 (1일 기준)**
   - 매월 1일 00:00(설정 가능)에 새로운 청구 주기가 시작되어 사용량이 자동으로 0분으로 초기화되고 영상통화가 다시 허용됩니다.

4. **이번 달 사용량 수동 보정**
   - 이미 이번 달에 300분을 초과 사용한 경우, [부모 설정]에서 사용량을 `300`으로 입력해두면 11월 잔여 기간 동안 발신 영상통화가 즉각 차단됩니다.

5. **부모에게 영상통화 종료 시 SMS 자동 전송**
   - 영상통화가 끝날 때마다 설정된 부모 번호로 문자(SMS)를 자동 전송합니다.
   - 전송 내용: 발신 시각, 통화 상대방(연락처 이름 및 전화번호), 통화 시간, 이번 달 누적 사용량, 한도 초과 자동종료 여부

6. **부모 PIN 보호**
   - 자녀가 임의로 앱을 끄거나 한도를 늘리지 못하도록 SHA-256 솔트 해시 기반 부모 PIN 설정이 적용되어 있습니다.

---

## 📱 설치 및 설정 방법

1. `VideoCallBlocker.apk`를 빌드하거나 다운로드하여 자녀 폰에 설치합니다.
2. 앱 최초 실행 시 **부모 PIN (4자리 이상)**을 설정합니다.
3. 화면에 안내되는 필수 권한을 모두 허용합니다:
   - **전화 · 통화기록 · 문자 권한** (`READ_PHONE_STATE`, `READ_CALL_LOG`, `ANSWER_PHONE_CALLS`, `SEND_SMS`)
   - **사용정보 접근 권한** (음성통화 중 카메라 사용 오탐 방지)
   - **배터리 최적화 제외** (백그라운드에서 감시 서비스가 종료되지 않도록 보장)
   - **알림 권한** (한도 80% 경고 및 차단 알림)
4. **부모 설정** 진입:
   - **알림 받을 부모 번호**: SMS 수신할 번호 입력 (예: `01012345678`)
   - **월 영상통화 한도**: 기본 250분 권장 (통신사 300분 한도 대비 안전 마진)
   - **이번 달 사용량 보정**: 이미 초과한 경우 `300` 입력 후 저장

## 🏗️ 빌드 방법 (CLI / Android Studio)

### 필수 요구사항
- JDK 17 이상
- Android SDK (compileSdk 35, minSdk 29)

### 릴리스 APK 빌드
```bash
./gradlew assembleRelease
# 빌드된 APK 경로: app/build/outputs/apk/release/app-release.apk
```
